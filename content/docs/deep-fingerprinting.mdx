Deep Failure Fingerprinting, shipped in v0.4.0, hashes failure content
with SHA-256, truncated to 16 hex characters.

```ts
fingerprint: "a1b2c3d4e5f6a7b8"
```

## Never throws

Fingerprinting falls back to a fixed value (`0000000000000000`) rather
than raising an exception.
