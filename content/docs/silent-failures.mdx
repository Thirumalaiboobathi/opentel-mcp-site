A silent failure is when an MCP tool call returns a successful JSON-RPC
2.0 envelope, but the tool result itself has `isError: true`.

## Why standard instrumentation misses this

```json
{
  "result": {
    "isError": true,
    "content": [{ "text": "Connection timeout" }]
  }
}
```
